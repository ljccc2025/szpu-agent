# 运维知识库总览与分类结构

《Linux 系统管理与运维》课程讲义 · 深圳职业技术大学

本知识库按"运维全生命周期"组织，共 14 个模块，各模块内容相互独立、按统一结构编写（核心概念 → 关键知识点 → 常用工具 → 典型实践），既可系统学习，也可日常查阅。

## 分类结构

### 一、基础服务层
- 第5章 Nginx 服务部署：静态站点、反向代理、负载均衡入门
- 第12章 网络运维：TCP/DNS/负载均衡原理与故障定位

### 二、可观测性层
- 第6章 监控与告警体系：指标采集、告警分级与降噪
- 第7章 日志管理与分析：集中式日志、结构化与链路追踪

### 三、交付与变更层
- 第8章 CI/CD 与发布工程：流水线、金丝雀与回滚
- 第9章 配置管理与 IaC：Ansible/Terraform、GitOps、防配置漂移
- 第10章 容器与 Kubernetes 运维：Pod 生命周期、探针、扩缩容

### 四、数据与可靠性层
- 第11章 数据库运维：主从复制、慢查询、备份恢复
- 第15章 备份与容灾：RTO/RPO、3-2-1 原则、容灾等级
- 第14章 故障应急与复盘：应急响应流程、无指责复盘

### 五、治理与优化层
- 第13章 容量规划与性能优化：压测、扩容决策
- 第16章 安全与合规：基线加固、漏洞管理、审计
- 第17章 SRE 与服务质量管理：SLI/SLO/SLA、错误预算
- 第18章 成本优化 FinOps：资源画像、降本三板斧

## 使用建议

初级工程师建议按 5→12→6→7→8 顺序打基础；中级工程师重点学习 10、11、14、15；准备晋升或面试可精读 13、16、17、18。
